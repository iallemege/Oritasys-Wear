# Oritasy's Wear

Nuclear Option BepInEx gameplay pack extracted from Oritasy.

- Hard dependency: `bia.runtime` (BIA.Runtime included in release zip)
- Soft dependency: `com.iallemmege.oritasy`
- Watermark: bottom-right **Oritasy™**

## Install
1. Install BepInEx for Nuclear Option
2. Drop `OritasyWear.dll` and `BIA.Runtime_*.dll` into `BepInEx/plugins`
3. Disable the matching feature in full Oritasy config if both are present
